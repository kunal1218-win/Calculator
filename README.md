# 🧮 Calculator Web Application

A simple and user-friendly calculator web application developed using **HTML, CSS, and JavaScript**. The calculator performs basic mathematical operations through an easy-to-use interface.

## 📌 Project Overview

The Calculator Web Application is a beginner-friendly project created to demonstrate the use of HTML for webpage structure, CSS for styling, and JavaScript for implementing calculator functionality.

The application allows users to perform basic arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Decimal calculations

It also provides **Clear (C)** and **Delete (DEL)** buttons.

## 🎯 Objectives

The main objectives of this project are:

1. To understand the basic concepts of HTML, CSS, and JavaScript.
2. To create an interactive web application.
3. To implement arithmetic operations using JavaScript.
4. To understand event handling in JavaScript.
5. To learn how to upload and manage a project using GitHub.

## 🛠️ Technologies Used

| Technology | Purpose                                    |
| ---------- | ------------------------------------------ |
| HTML5      | Creates the structure of the calculator    |
| CSS3       | Provides styling and layout                |
| JavaScript | Handles calculations and user interactions |
| GitHub     | Stores and manages the project             |

## ✨ Features

* Simple and clean user interface
* Addition operation
* Subtraction operation
* Multiplication operation
* Division operation
* Percentage operation
* Decimal values
* Clear display functionality
* Delete last character functionality
* Error handling for invalid expressions

## 📂 Project Structure

```text
calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

The HTML file creates the structure of the calculator, including the display and buttons.

### `style.css`

The CSS file controls the appearance, spacing, alignment, buttons, and overall calculator layout.

### `script.js`

The JavaScript file handles button clicks, displays entered values, deletes characters, clears the display, and calculates results.
